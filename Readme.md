## 📖 О проекте

Официальный сайт компании ООО «Оптом Ланфан», 
занимающейся импортом и экспортом автозапчастей 
и нефтяного оборудования из Китая.

🌐 Сайт: https://lfobdm.ru

## 🎯 Цель проекта

Разработка корпоративного сайта для компании,
занимающейся импортом и экспортом автозапчастей и промышленного оборудования из Китая.

Основная задача — создать удобный, адаптивный и информативный веб-ресурс
для привлечения клиентов и демонстрации ассортимента продукции.


## 🚀 Функциональность

- Просмотр каталога автозапчастей и нефтяного оборудования, а также возможность заказа деталей
- Просмотр информации о компании
- Контактная информация
- Форма записи / обратной связи
- Адаптивная верстка


## 📂 Главные страницы

- **Главная** - Обзор компании, основные направления деятельности, преимущества сотрудничества и краткая информация о поставках из Китая
- **Каталог** - Перечень автозапчастей и нефтяного оборудования, доступных для импорта и оптовых поставок
- **О компании** - Информация об ООО «Оптом Ланфан», специализация, опыт работы и особенности сотрудничества
- **Запись / Заявка** - Форма для отправки запроса на сотрудничество или уточнения информации по товарам
- **Контакты** - Контактные данные компании, способы связи и форма обратной связи

## 🛠 Используемые технологии

- HTML5
- CSS3
- JavaScript
